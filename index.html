操作方式和實體機一樣

sin 45°45 → sin
log 100100 → log

MODE 模式切換

SDMODE .統計模式

FIXMODE 7 0–9固定小數位

DEG / RAD 怎麼選？

題目寫 30°、45°、60° 時，先設 DEG：MODE 4。

題目使用 π/6、π/4、π/3 時，先設 RAD：MODE 5。

RAD 模式算 sin(π/6)：
SHIFT → EXP(π) → ÷ → 6 → = → sin，結果為 0.5。

也可用 SHIFT MODE 後按 5/6/7，把目前顯示的角度值換算成 RAD / GRA / DEG。

常用第二功能

  • SHIFT + x²：√x
  • SHIFT + log：10ˣ
  • SHIFT + ln：eˣ
  • SHIFT + sin/cos/tan：反三角函數
  • SHIFT + EXP：π
  • SHIFT + =：%
  • SHIFT + 1/2/3：nPr / nCr / x!

SD 統計模式

先按 MODE .。輸入資料後按 M+，此時 M+ 會當作 DATA；SHIFT + M+ 會當作 DEL。要一次清除全部統計資料，按 SHIFT + AC（SAC），會回到 0 筆資料的狀態。

SHIFT + 7/8/9 可求 x̄、σn、σn−1；SHIFT + 4/5/6 可求 Σx²、Σx、n。
